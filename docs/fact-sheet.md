| 주장 | 출처 |

| 주간 커밋 차트 | 같은 데이터를 월요일 기준 주 단위(UTC)로 집계 |
| 두 저장소 모두 에이전트 지침 `AGENTS.md`를 둠 | GitHub API (claude-pet `AGENTS.md` 56 KB, llmwiki_json `AGENTS.md`) |
| 채팅 예시 | **예시**입니다. 사이트에 "예시"라고 표기 |
| "기획서는 AI와 나눈 대화에서 다듬었다" (K-Factory Hub) | 개발 기획서의 출처 표기("…정리 대화")와 창업자 설명 | **확인 필요**: AI 대화가 맞는지 |

트레일러 방식은 보수적입니다. 트레일러를 붙이지 않은 AI 사용분은 세지 않습니다. 반대로 AI가 쓴 코드를 사람이 크게 고쳐도 트레일러가 있으면 셉니다.

사이트에는 "Claude와 함께 만든다" 같은 슬로건을 쓰지 않습니다. Claude 이름은 제품 이름(Claude Pet)과 제품 사실(Claude Pet이 Claude Code 로그인을 읽는다, llmwiki_json 카드의 연동 칩)에만 남아 있습니다.
